# retrogames4.net

A retro-styled games website built with HTML, CSS, JavaScript, and Tailwind CSS.

## Overview

`retrogames4.net` is a browser-based retro games project with a neon arcade-inspired visual style.

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Install Dependencies
Run `npm install` to install the required dependencies.

### Build CSS
Run `npm run build:css` to compile Tailwind CSS and generate `./css/tailwind.css`.

### Watch CSS During Development
Run `npm run watch:css` to watch for changes and rebuild CSS automatically during development.

## Running the Website

Open `index.html` directly in your browser, or serve the project with any static development server.

## Technologies Used

- HTML
- CSS
- JavaScript
- Tailwind CSS
